# Voces grabadas

Subí acá el ZIP que exporta Tranqui desde **Grabar mi voz → Exportar para incluir en la app**
(por ejemplo `agustin.zip`). Al compilar, GitHub limpia cada frase (silencios, ruido de
fondo, volumen) y la voz queda incluida en la app como «Voz de Agustin» para todos.

Desde el celular: en GitHub, entrá a esta carpeta → Add file → Upload files → elegí el ZIP.
